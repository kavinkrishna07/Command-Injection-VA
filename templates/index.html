An app that builds its command with string concatenation — os.system("ping " + user_input) — would pass this entire string to the Windows shell. Characters like ;, &&, and | tell the shell to start a second command. That second command runs with the same permissions as the web application. This lab catches the pattern and stops before anything is executed.

Reference

Safe commands The input is validated against a known-good list before anything runs. Only approved tools are called, and the result is exactly what you see in the output box.
Injection demos Inputs containing ;, &&, or | are caught by the validator. The risky part is shown for educational purposes — nothing is executed.
How to prevent it Validate input first. Build the command as a list of arguments, not a single string. Call the process directly — never through a shell — and always enforce a timeout.
Running locally — for learning purposes only — no data leaves your machine
