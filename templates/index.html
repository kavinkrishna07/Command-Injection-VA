Reference

Safe Mode Input is checked against an allow-list regex. Subprocess is invoked with shell=False passing arguments as a list.
Unsafe Mode Input is concatenated into raw bash string (shell=True). Shell operators (;, &&, |) execute secondary commands directly.
How to Prevent It Never use shell=True or os.system() with user input. Enforce allow-list validation and pass arguments as lists.
